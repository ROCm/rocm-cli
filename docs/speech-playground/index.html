ROCm CLI speech API

OpenAI-compatible endpoints of a server started with rocm serve. Type, press Speak, and listen.

POST/v1/audio/speech Text to speech

Returns a WAV file. Served by rocm serve kokoro (CPU, demo) or rocm serve tts (GPU).
