ROCm CLI speech API

OpenAI-compatible endpoints of servers started with rocm serve. Type and press Speak, or Record and talk.

POST/v1/audio/speech Text to speech

Returns a WAV file. Served by rocm serve kokoro (CPU, demo) or rocm serve tts (GPU).
